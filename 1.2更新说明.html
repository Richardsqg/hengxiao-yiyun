  1. 广彩珐琅：目前为课程照片制作的约36秒静音图文导览，非实拍工艺宣传片，可后续替换。
  2. 陶艺与篆刻：沿用原陶瓷视频，排在第二位。
  3. 蓝白扎染：使用本次上传的视频，排在第三位。

凤冠现有两组照片素材，六个展位尚待补充。现有照片不构成连续360°实拍，也不支持任意俯仰角度的三维模型查看。每件作品建议拍摄36张、每次转10°，系统接受24—120张连续照片。不同作品不能混为同一圈序列。

启动与管理

先阅读同目录“开始使用.html”。安装 Node.js 24.x（至少24.15），运行启动脚本或依次执行 node scripts/configure.mjs、node runtime/server.mjs。普通部署不需要 npm install。后台地址为正式网址后加 /admin，使用自行设置的管理密码。

国内独立版的管理员密码与当前在线托管站登录方式不同。托管站后台使用授权的 ChatGPT 身份。

分享海报由网页生成，不依赖微信分享接口；微信内可保存图片或长按操作，实际行为以手机权限为准。图标支持添加到主屏幕，本产品是网页，不是已审核上线的微信小程序。

上线前建议

  1. 优先补齐凤冠连续环绕照片，拍摄要求详见配套手册。
  2. 补充广彩珐琅实拍宣传片，并统一三部影片的片头、封面和字幕。
  3. 正式使用前，以学校确认的作品名称、作者及课程名称校对图文；公开学生照片应由学校确认使用范围。
  4. 确定国内服务器和正式域名后部署，再生成最终二维码；二维码本身不能改变目标网站的网络可达性。

独立版页面资源均随包提供，没有远程字体或 JavaScript CDN 依赖。当前公开托管网址不等于国内部署，尚未完成中国内地各运营商及微信真机验收。此次通过构建与接口测试；未完成浏览器视觉验收。
