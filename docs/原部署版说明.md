# 横小艺韵：独立部署版

先用浏览器打开 **开始使用.html**。本压缩包包含已构建网站、服务器程序、源代码和测试，不包含 Node.js 安装程序。

- 运行要求：Node.js 24.x LTS（至少24.15），无需安装运行依赖。
- 首次配置：`node scripts/configure.mjs`
- 启动：`node runtime/server.mjs`
- 管理：正式域名的 `/admin`，使用配置时设置的密码。
- 备份：暂停后台上传，然后 `node scripts/backup.mjs`。
- 二维码：`/api/qr.png`；配置时同时写入 `data/gallery-qr.png`。
- 构建源码才需要：`npm install`，然后 `npm run build`。普通部署无需这两步。
- 自动测试：`npm test`，使用临时数据库与本机 HTTP 服务，不写入正式留言。

这是可部署交付包；尚未部署到用户的国内服务器，也未完成国内微信真机测试。在线展示站已同步升级，原网址继续使用。2026-10-12 已核对旧站线上数据库：留言与素材设置均为0条，暂无历史记录需要迁移。最终上线前仍应再次检查，迁移新增记录。

代码根据已交付站点重组为 React 静态界面 + Node.js HTTP 服务 + SQLite + 本机媒体目录。观看路径没有远程字体、外部 JavaScript CDN、ChatGPT 登录或 GitHub 下载依赖。引用资料链接仍可由观众主动打开。

配套材料见 **展览配套手册.html**，字幕格式见 materials 目录。

本版本适合单台服务器、单个应用实例的小型展览。数据目录应位于持久化磁盘，不要使用临时容器文件系统。暂不支持多实例共享数据库、高并发负载均衡或断点续传。视频上传分块传输，失败可重新上传；未完成的任务一日后清理，旧已发布媒体暂不自动删除。

安全实现：密码 scrypt 哈希；8小时 HttpOnly / SameSite=Strict 管理会话；HTTPS配置下 Secure Cookie；同源写入；登录与留言限流；上传体积和格式约束；静态根目录隔离；参数化 SQL；Excel 使用字符串单元格；配置与数据不进 Git。默认仅监听 127.0.0.1:3000，由 Caddy 提供公开 HTTPS。
