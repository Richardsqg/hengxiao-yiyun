横小艺韵 1.4.3-desktop

完整本机 / 同 Wi-Fi 部署包 · 2026-10-21

91帧凤冠360、放大后继续旋转、后台视频上传优化和Node.js运行环境均已整合。无需另装Node、无需安装小补充包、无需npm install。

先准备

  1. 关闭原展馆服务：原启动窗口按Ctrl+C；Windows若提示终止批处理，输入Y并回车。
  2. 将新ZIP全部解压到一个新文件夹，保留旧包。不要在ZIP内部运行启动文件，不要只复制dist。
  3. Windows包适用Windows 10/11的x64或ARM64；Mac包适用macOS 13.5及以上的Apple芯片或Intel电脑，启动器自动识别。整个文件夹至少预留1GB空间。

Windows：手机同Wi-Fi扫码

  1. 打开解压后的hengxiao-yiyun-1.4.3-desktop文件夹。
  2. 普通双击 Windows_同WiFi扫码启动.bat，无需管理员身份。
  3. 首次没有旧data配置时，按下面“首次设置”操作。之后不必重复设置。
  4. 启动成功后会自动打开二维码页面。Windows防火墙如有提示，允许Node在专用网络通信。
  5. 手机连接与电脑相同的路由器/Wi-Fi，使用相机或微信扫码。电脑也可点击二维码下方网址。
  6. 黑色窗口保持开启。停止时在窗口按Ctrl+C，提示终止批处理时输入Y。

只在电脑本机使用时，双击 Windows_启动.bat，浏览器地址为 http://127.0.0.1:3000 。

Mac：手机同Wi-Fi扫码

  1. 打开解压后的hengxiao-yiyun-1.4.3-desktop文件夹。
  2. 双击 macOS_同WiFi扫码启动.command。首次被系统阻止时，在访达中右键此文件→“打开”，按系统提示确认来源。
  3. 如果macOS提示“权限不够”，在终端输入 chmod +x （末尾留一个空格），把这个.command文件拖入终端，再按回车。然后重新双击启动。
  4. 首次没有旧data配置时，按“首次设置”操作。
  5. 允许Node接收传入网络连接。启动后自动打开二维码页，手机连接同一路由器/Wi-Fi并扫码。
  6. 保持终端开启，Mac不要休眠。停止时在终端按Control+C。

只在Mac本机使用时，双击 macOS_启动.command，浏览器地址为 http://127.0.0.1:3000 。

首次设置：只需做一次

  1. 看到“正式网址”时直接按回车，使用本机默认值。
  2. 输入你自己设置的管理员密码，至少12个字符，再输入一次。输入密码时不显示字符，属于正常情况。
  3. ICP备案号、公安备案号在本地使用时可直接按回车留空。
  4. 配置完成后会继续启动服务并打开浏览器。以后使用同一个启动入口，密码和数据保存在本项目data文件夹里。

凤冠放大后如何继续360旋转

  • 手机：双指张开放大，然后单指左右拖动，继续旋转91帧凤冠。捏合可缩小。
  • 电脑：鼠标滚轮或“＋”按钮放大，然后鼠标左键按住左右拖动旋转。
  • 移动画面细看：点击“拖动平移”，拖动画面；看完点击“拖动旋转”继续转动。两种模式均保留放大倍率。
  • 下方左右箭头、角度滑条和自动旋转在放大后均可使用，不会将图片缩回100%。
  • “全屏查看”里的图片同样支持放大与旋转；“重置视角”恢复100%。
  • 这是原实拍图片序列的水平环绕，可放大至600%；不包含任意俯仰视角。其他展位继续按已有素材显示。

后台视频上传与播放

  1. 在二维码页面点击“电脑打开管理员后台”，或在当前展馆网址后加 /admin。用刚设置或迁移的原密码登录。
  2. 进入“影片与360°”，在需要替换的FILM卡片选择MP4。当前上限400MiB，151MB在范围内。
  3. 等待编码检查，点击本地预览的播放按钮，确认有画面且声音符合原片。
  4. 勾选画面和声音确认框，再点“确认画面正常，上传并替换”。等进度100%及发布完成提示。
  5. 到公开影像展厅播放，并拖动进度检查。

兼容格式为MP4、H.264（8位4:2:0）、可选AAC-LC音轨。若提示编码不兼容，请用视频软件导出兼容版再上传。已有FFmpeg时，也可使用包内“另存兼容视频”入口；本包未附带FFmpeg。

原151MB“掐丝珐琅”视频未被云端读取，本包保留原三部默认影片；你可通过新版后台上传实拍视频。若以前手动导入过 dist/assets/film-01-qiasi.mp4，请一并复制该文件到新包对应位置。

保留旧密码、留言和后台上传素材

如果要沿用旧数据：先停止旧服务，在新包第一次启动之前，把旧项目的整个 data 文件夹复制到新项目文件夹内。不要只复制数据库，不要在旧服务运行或上传时复制。这样可沿用密码、留言和data/media中的后台上传文件。旧包继续保留作备份。

如果已经在新包创建了新data，先停服务并另行保存新data，确认需要使用哪一份后再迁移，不要把两份数据库直接合并。

扫码打不开或启动失败

  • 手机与电脑连接同一可互访的局域网；关闭访客网络/设备隔离，允许防火墙通信。普通家庭Wi-Fi下核心浏览不需要互联网或翻墙。
  • 换Wi-Fi后停止并重新启动“同WiFi扫码”入口，扫描新二维码。保持电脑开机、服务窗口开启。
  • 端口3000被占用：停止之前的展馆窗口，只运行一个启动入口。
  • 包内隐藏的.runtime目录保存Node程序，不要删除。完整解压后启动器会优先使用它。
  • 第一展位若之前在后台上传过另一组360，原上传组会继续优先显示。可在后台选择展位1，选择本包dist/assets中crown-01-frame-001.webp至091.webp并上传启用。
  • 启动报错时保留窗口里的完整文字；不要通过删除data来排查。
