# 视频上传与有声无画面 · Mac / Windows补充

## 本次检查结果

当前独立版前后端总上传上限均为400 MiB（419430400字节），每片8 MiB，151MB属于允许范围。没有发现30MB上限或导致画面被隐藏的样式规则。

原流程只核对MP4容器开头、分片大小和哈希，不能区分H.264、HEVC/H.265或仅音轨MP4。浏览器有时可以播放AAC音轨却无法解码视频轨，因此会有声音但没有画面。用户原151MB视频尚未提供可读取样本，本次不能确定它实际使用哪一种编码。

## 补充后的行为

- 后台选文件后先检查编码并显示本地预览，不立即上传。支持H.264 Baseline/Main/High、8位4:2:0，以及可选的AAC-LC音频；静音视频允许上传。
- 播放预览，确认画面和声音正常后勾选确认框，再点击上传替换。
- 服务端拼接后再次校验视频轨与编码，通过后才发布；不兼容、纯音轨或损坏文件被拒绝，旧视频继续保留。该检查不等于对整部视频的每一帧做完整解码。
- 公共播放器在检测到无画面轨或解码问题时显示兼容性提示，不再只归因为网络。
- 容量仍为400 MiB，151MB无需为了容量压到30MB。

## 安装补充包

1. 关闭原展馆的启动窗口，解压对应系统的补充ZIP。
2. Mac双击「安装视频上传补充.command」，选择原部署包中含package.json、runtime、dist的目录。Windows双击「安装视频上传补充.bat」，把该目录拖入窗口并按回车。
3. 安装会校验程序结构、备份需更新的程序文件，再逐个加入新文件。不要手动替换整个runtime、dist或data文件夹。
4. 用原启动入口重新运行，刷新管理员页面，重新选择待上传视频，先播放本地预览。

本补充不含视频、凤冠图片、Node或node_modules，不需要重新下载整站、安装依赖或构建。已安装的凤冠360补充仍保留。原配置、密码、留言及上传文件不由安装器改写。此前已有后台自定义视频仍保持当前地址，直到新片校验通过后替换。

用户的1.4.2-desktop 2原ZIP和真实Mac/Windows机器不在本环境中；本包基于当前仓库独立版接口，原接口不匹配时会停止，不能把云端Chromium验证称为Windows或Safari真机验收。

## 已经上传但只有声音的视频

安装程序不会自动改变既有视频的编码。请拿原片导出兼容版后重新上传：MP4容器，H.264，8位、4:2:0，AAC-LC音频，建议720p/1080p。

新增的「另存兼容视频」入口可使用本机已有的FFmpeg转换，并另存为「原文件名-兼容版.mp4」，不会覆盖原片。Mac双击「macOS_另存兼容视频.command」选原片；Windows双击「Windows_另存兼容视频.bat」并拖入原片。

如果本机没有FFmpeg，入口会明确停止；本补充不自动下载大转码器。可使用自己的视频工具导出上述格式。仅把MOV、HEVC或其他文件改名为.mp4不会改变编码。

## 恢复

更新前程序文件保存在 `backups/video-upload-fix-20261020/`，保持原相对目录。关闭服务后按原目录恢复这些备份即可撤回程序更新；不要删除或恢复覆盖data目录。新增资源文件可以保留，不影响恢复。
