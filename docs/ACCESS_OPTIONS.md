# 手机扫码、免翻墙与正式部署

本轮先交付可完整管理内容的 Windows x64 便携软件，并提供同 Wi-Fi 扫码模式。若要校外手机流量随时访问，需要另外部署公网服务；二维码只保存网址，不会改变网络可达性。

## 方案比较

| 场景 | 推荐方式 | 是否依赖境外站点 | 当前状态 |
| --- | --- | --- | --- |
| 学校、教室、展厅现场 | Windows便携软件 + 手机连同一Wi-Fi | 否；网页、图片、三视频、留言与后台均由电脑本地提供 | 已实现启动、二维码、独立数据保存；需Windows和手机现场验收 |
| 家长在家或用手机流量 | 中国内地服务器 + 域名 + HTTPS | 否；使用独立Node/SQLite版，不要求访客或管理员登录ChatGPT | 程序与部署示例已备齐；尚无服务器、域名，未部署 |
| 学校已有网站基础设施 | 请学校信息部门提供服务器及独立子域名，部署同一套程序 | 按学校实际网络 | 推荐先询问，可避免重复购买资源 |
| 香港等地区服务器 | 部署独立版，先做国内移动/联通/电信和微信实测 | 不要求用户安装代理，但不能承诺所有地区直连速度 | 可选；域名、服务商和具体手续需核对 |
| 原Sites展示站 | 当前 chatgpt.site 网页 | 有境外网络依赖，不能保证国内免翻墙直连 | 已有发布，继续更新第一片；不作为国内稳定访问承诺 |

## 学校现场：现在就能准备

1. 完整解压1.4.1便携软件，不只复制HTML。双击 `Windows_一键运行.bat`，选2“同Wi-Fi”。
2. 电脑与手机连接同一Wi-Fi/局域网；有多个网卡时，选与手机在同一网络的Wi-Fi地址。
3. 首次在电脑设置管理员密码，软件会打开私有“打开与扫码”面板，显示二维码。观众手机扫码后直接浏览，不安装软件或登录ChatGPT。
4. 电脑保持开机、服务窗口保持开启；Windows若询问网络权限，允许专用网络访问。不要关闭整个防火墙。
5. 先用一台实际手机测试四模块、三视频、图片缩放及一次问卷。访客网络/校园网的客户端隔离可能阻止互访，需学校网络管理员协助。
6. 换Wi-Fi、电脑IP或启动端口变化后，重新启动并使用新二维码。这个二维码不适合给异地观众或手机流量访问。

软件只读写 `data/portable/` 业务目录，不把上传、留言和密码交给外部服务。内置网页没有为正常展示而引用外部CDN，离线局域网仍可使用已自带和本地上传的素材。内容首次还原来自软件内视频分片，不另行联网下载。

## 校外也要访问：上线所需信息

优先使用学校已有服务器和域名。若学校没有，选择国内云服务商的服务器与域名，按服务商要求完成账号实名、域名和网站备案等手续，再配置HTTPS证书。

交给部署人员的内容已经在项目中：

- Node.js24.15及以上的24.x、独立React已构建网页、SQLite和本地媒体，无需另建另一套系统。
- `deploy/Caddyfile.example`：HTTPS反向代理示例。
- `deploy/fenghua.service`、`deploy/install-service.sh`：Linux服务管理示例。
- `scripts/configure.mjs`：首次正式网址与管理员密码配置。
- `scripts/backup.mjs`：数据库、配置与上传媒体的完整备份。
- 只将Web服务通过HTTPS暴露给公网；不要把SQLite、备份、源码或密码配置直接当公开目录提供。

服务器需预留当前素材、未来上传和独立备份空间。带宽与同时观看人数相关，不能只按服务器CPU选择。例如每路视频约1.6Mbps，20人同时看需要约32Mbps的总视频流量，另加图片和页面开销；这是容量估算，不代表购买套餐或实测性能承诺。大规模展览可另评估国内对象存储/CDN，接入和费用届时确认。

需要用户后续提供：选定的服务器/域名或学校信息部门的接入方式，以及允许部署的账号权限。当前没有购买、创建收费服务、修改域名或迁移旧站真实数据。收到这些后再完成正式部署、测试手机直连和生成长期二维码。

## 这个软件能改什么

后台可继续编辑既有课程图文、替换图片、上传360序列、替换视频/封面/字幕、处理留言和导出Excel。具体菜单和限制见 [SOFTWARE_GUIDE.md](SOFTWARE_GUIDE.md)。版式、主题、校徽、问卷题目和课程结构数量等系统级调整仍需修改源码并构建，不能把现有后台称为任意细节的可视化编辑器。
