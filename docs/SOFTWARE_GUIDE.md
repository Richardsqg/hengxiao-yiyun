# 横小艺韵：软件使用与后续内容维护

本说明适用于在现有 1.4 项目上继续维护的独立版。项目保留一套应用、一个 GitHub 仓库，公众页面、管理后台、数据库和媒体服务一同运行。不要只复制 `dist/index.html`：图片浏览可以是网页，上传、登录、留言和 Excel 还需要随包提供的服务。

## 1. 在 Windows 电脑运行软件

如果下载的是本次完整 Windows 便携包：

1. 将整个压缩包解压到一个新文件夹，不覆盖旧项目或旧数据。
2. 双击 `Windows_一键运行.bat`。便携包内置 Windows x64 的 Node.js 24，正常运行不需要另装 Node.js，也不需要 `npm install`。
3. 按窗口提示选择“仅本机”或“同 Wi-Fi”。第一次使用时，由你在电脑终端设置管理员密码，至少 12 个字符；密码输入时不显示字符。
4. 服务就绪后会自动打开私有“打开与扫码”面板，包含二维码、观众入口和管理员登录按钮。保持启动窗口开启；也可在显示的展馆地址后加 `/admin` 打开管理后台。
5. 结束使用时关闭启动服务；电脑关机、休眠或服务停止后，手机将无法访问这台电脑上的展馆。

便携包使用独立的 `data/portable/`，不会自动导入其他版本的数据库。这个目录会保存配置、密码哈希、留言、已发布内容和后台上传的媒体。以后更新软件时请保留它；旧版数据迁移前先备份，不能将空的新目录覆盖旧目录。

本次1.4.1便携版本以及对应GitHub标签均已包含官方 Windows x64 Node.js 24.22.0 的 `runtime/node.exe` 和许可证，不必再安装Node。若使用未包含运行程序的旧源码，则需先安装 Node.js **24.15 或更高的 24.x，且低于 25**，再双击 `Windows_本机测试.bat`。它使用单独的 `data/local-preview/`；原 `Windows_启动.bat` 默认使用原有 `data/`。不同启动方式的数据目录不同，不要以为内容消失就删除目录或重新覆盖数据。

Windows ARM、macOS 和 Linux 不属于此次 Windows x64 便携运行环境；源码独立版的运行要求仍以 `package.json` 为准。

## 2. 电脑、手机扫码与公网访问的区别

| 使用方式 | 观众如何打开 | 使用条件 |
| --- | --- | --- |
| 仅这台电脑 | 启动窗口给出的 `127.0.0.1` 地址 | 软件正在运行；此地址不能转发给手机使用 |
| 教室、展厅同 Wi-Fi | 启动窗口给出的局域网地址或对应二维码 | 手机与电脑在同一 Wi-Fi/局域网，电脑保持开机，系统允许软件在专用网络通信 |
| 不同地点、使用手机流量 | 稳定的公网 HTTPS 域名及其二维码 | 需要把完整服务部署到可公开访问的服务器；二维码本身不会让电脑变成公网服务器 |
| 当前 Sites 托管网址 | 原展馆的 `chatgpt.site` 地址 | 与独立版分别运行，无法承诺中国内地网络无需代理稳定访问 |

同 Wi-Fi 模式适合学校现场展示，不需要观众安装软件或使用代理。使用启动窗口显示的实际地址，不要手动将 `127.0.0.1` 换成猜测的 IP。电脑换网络后，IP 可能变化，需要重新启动并重新生成二维码。公共 Wi-Fi 的“客户端隔离”、访客网络或学校网络策略可能阻止手机访问电脑；可请学校网络管理员协助。无需关闭整个系统防火墙。

用于正式展览前，先用另一台手机扫码打开四个展区，播放三部影片、缩放图片，再提交一份测试问卷。HTTP 局域网地址适合可信的现场网络；管理员不要在不可信的公共网络中输入管理密码。

如果要让家长在家里、不同城市或使用手机流量直接访问，建议部署到**中国内地云服务器 + 自有域名 + HTTPS**，按服务商要求办理域名实名、网站备案等手续，再做国内网络实测。也可评估香港等地区服务器，通常不使用内地服务器的 ICP 备案接入流程，但访问速度、稳定性和实际合规要求仍需核对。当前没有购买、创建或绑定服务器和域名，也没有迁移原站真实数据。

## 3. 各页面与后台菜单

在当前展馆地址后添加路径即可直接打开，例如 `http://电脑IP:端口/films`。实际 IP 和端口以启动窗口为准。

| 页面路径 | 内容 |
| --- | --- |
| `/` 或 `/crown` | 凤冠360展示；总入口默认进入这里 |
| `/culture` | 文化寻根、三个系列和五门课程 |
| `/films` | 影像展厅，依次为掐丝珐琅、陶艺篆刻、蓝白扎染 |
| `/voices` | 观展留言和问卷 |
| `/admin` | 登录后的管理后台；不出现在公众四入口导航中 |
| `/guide` | 网页使用和拍摄说明 |
| `/preview` | 已保存图文草稿的私密预览，需先登录后台 |
| `/poster` | 二维码展板，需先登录后台 |

独立版管理员使用首次启动时设置的密码。原 Sites 站的 `/admin` 使用创建展馆的 ChatGPT 账号及该站授权，两者的登录方式和数据不相通。独立版源码更新、GitHub 提交或本机编辑，不会自动发布到原 Sites 网址。

后台四个菜单的用途如下：

| 后台菜单 | 常见操作 |
| --- | --- |
| 留言与统计 | 查问卷、搜索昵称或留言、筛选未读/已阅、标记、删除、导出 Excel |
| 影片与360° | 替换三部影片、改封面和字幕、显示或隐藏影片、上传各凤冠展位整组环绕照片 |
| 图文与发布 | 修改展馆资料、课程图文、文物图注、凤冠鉴赏照片；保存草稿、预览、发布和恢复图文历史 |
| 展览工具 | 独立版运行/备份状态、二维码展板、开展前检查提示 |

## 4. 修改图文与课程图片

进入 **图文与发布**，先选课程系列，再展开对应资料。

- 可修改文化背景、年代说明、观察角度正文、名词解释、课程完整标题、课程简介、各门课程的名称、年级、目标和已有教学活动。
- 展开“文化代表图片”或“课程成果图片”，点击“替换第 X 张”选择新图片，再填写图片标题、描述、图注、作者、许可及来源网址。
- 当前每个系列的两类图片各保留五个位置。后台可替换这些位置；自由新增第六张、增删课程或调整分区数量需要后续修改程序。
- 图片接受 JPG、PNG、WebP，单张最多 **8 MiB**。建议上传适合手机阅读的清晰图，保留原图在自己的资料文件夹中。不要把 HEIC 文件直接改扩展名冒充 JPG。
- 来源网址填写 HTTPS 网页地址；图片文件从电脑上传，不在图片栏粘贴外站图片地址。

图文修改完成后依次点击 **保存草稿 → 预览已保存草稿 → 发布草稿**。预览需要登录，观众看不到未发布的文字与图文引用。改了内容但尚未保存时，“发布草稿”会被禁用，先保存再发布。

系统保留最近十个图文发布版本。点击历史版本的“载入草稿”后先核对预览，再发布才对观众生效。尽量只开一个编辑窗口；提示“内容已被其他窗口更新”时，先保留自己尚未保存的文字，再重新读取服务器内容，避免互相覆盖。

## 5. 凤冠鉴赏照片与真正的360°序列

普通鉴赏图片位于 **图文与发布 → 八个凤冠展位**：

1. 选择展位 1—8，填写该件作品名称与真实的素材说明。
2. 使用“替换照片”“移除此照片”或“添加鉴赏照片”。每个展位最多 12 张。
3. 保存草稿、预览、发布。

真正的整圈照片位于 **影片与360° → 360°环绕照片**：

1. 固定相机、灯光、背景，将**同一件**作品放在转台上等角度拍摄完整一圈；推荐 36 或 72 张。
2. 按 `001.jpg`、`002.jpg` 等顺序命名，确保第一张到最后一张按同一方向连续变化。
3. 选择正确展位，一次选中该件作品整组图片。允许 24—120 张，每张最多 8 MiB；建议长边约 1600 像素，减少手机加载量。
4. 点击“上传并启用360°环绕”，保持页面开启。只有全部上传和提交成功才替换该展位当前序列；成功后观众刷新即可使用。

这里的360°是实拍图片的水平环绕、自动旋转与缩放，不能任意改变俯仰角度，不是三维建模。不同作品的正面、展陈合照或 AI 猜测的背面不能混成真实的一圈。

当前共有八个展位，但**并没有八件完成的真实360°作品**：展位 1 为三张多角度图，展位 2 为两张校园展陈照片，展位 3—8 仍缺实际作品资料；所有展位仍待补真实完整环绕序列。具体资料状态见 [MEDIA_INVENTORY.md](MEDIA_INVENTORY.md)。后台目前没有单独清空已发布整圈序列或逐张重排的按钮；需要更改时准备完整且顺序正确的一组重新上传，误传后先停止继续操作并从备份安排恢复。

## 6. 替换视频、封面和字幕

在 **影片与360° → 三部宣传影片** 找到对应位置，第一格即“掐丝珐琅”：

1. 填写影片标题与简短介绍。
2. 选择 MP4 文件，点击“上传并替换此影片”，等到显示成功再离开页面。后台限制为每部最多 **400 MiB**，采用分段上传；聊天附件的读取上限与这个后台上传限制不同。
3. 为兼容苹果、安卓和微信，推荐 MP4 内使用 **H.264 视频 + AAC 音频**。文件扩展名是 MP4 不代表其内部编码一定兼容；HEVC 原片可能需要先转码。
4. 下方“影片 X · 封面与字幕”可更换封面、修改标题和介绍、上传 UTF-8 编码的 `.vtt` 字幕，或勾选隐藏影片。封面遵循图片大小和格式限制；字幕最多 180,000 字节，需包含 `WEBVTT` 头和时间轴。
5. 点击“保存影片资料并发布”，再打开 `/films` 检查画面、声音、拖动播放位置和字幕。

影片下方约 200 字的课程简介在 **图文与发布 → 对应课程系列 → 约200字课程介绍** 修改；视频卡片的简短介绍属于单独的影片资料，两处用途不同。

**视频上传、影片资料保存、360°整组上传都会立即发布，不经过图文草稿流程，也不属于最近十个图文版本。** 替换视频会清空旧字幕，需要为新视频重新配字幕；封面若不更换会沿用此前封面，注意画面是否仍匹配。隐藏只停止在展馆中提供播放，不能作为删除文件或让已分享的媒体地址失效的手段。

系统不会把无声片自动变成有声片，也不会自动补齐真实解说或字幕。字幕模板不能当作已经完成的课程字幕。原视频、字幕源文件和封面原图请另行保存。

## 7. 问卷、Excel 与完整备份

观众在 `/voices` 提交的问卷和留言只供管理员查看，不在公众留言墙展示。后台“留言与统计”可搜索、筛选并标记已阅。删除不可在后台撤销，删除前建议导出或备份。

点击“导出 Excel”得到真正的 `.xlsx` 文件，含“观展留言”和“问卷统计”两个工作表。留言表按当前搜索/筛选条件导出，统计表统计全部问卷；每次最多导出 20,000 条。数据时间按北京时间显示。问卷超过单次导出上限时应另行安排完整数据导出。

展览结束后，在“图文与发布”取消“开放观展留言”，填写关闭提示，再保存并发布；页面仍可继续浏览。

**Excel 方便阅读统计，不能完整恢复软件。** 独立版完整备份包括数据库、配置和上传的媒体，备份前暂停后台上传。便携包对应的数据目录为 `data/portable/`，在项目根目录的 PowerShell 中可运行：

```powershell
$env:DATA_DIR = Join-Path $PWD 'data\portable'
.\runtime\node.exe scripts\backup.mjs
```

使用源码与自行安装 Node.js 时，将第二行改为 `node scripts/backup.mjs`。如果使用 `Windows_本机测试.bat`，数据路径应改为 `data\local-preview`；其他安装须选择实际使用的 `DATA_DIR`，不能备份错目录。

备份生成在项目的 `backups/` 下。将备份复制到另一块硬盘或另一台设备，妥善保管；它包含管理员密码哈希和观众留言，不要提交 GitHub 或公开分享。后台“展览工具”中的时间只表示脚本曾完成备份，不表示已设置自动备份或已复制到其他设备。当前没有后台一键恢复数据库功能，恢复前需停止服务、保留现场副本，再核对目录和媒体。

原 Sites 站的数据库与上传文件属于该托管站，便携版备份脚本不能备份它们。以后若要迁移原站数据，需要另行导出、核对和导入，不要将“下载源码”误当成已取得线上留言和所有后来上传的素材。

## 8. 能自行修改到什么范围

| 修改内容 | 当前处理方式 |
| --- | --- |
| 已有展馆名称、简介、主办单位、展期、问卷开关 | 后台“图文与发布” |
| 已有三个系列、五门课程的文字和固定图片位置 | 后台“图文与发布” |
| 八展位名称、说明和最多 12 张鉴赏照片 | 后台“图文与发布” |
| 八展位的完整实拍360°照片组 | 后台“影片与360°” |
| 三部影片文件、标题、介绍、封面、字幕、显示状态 | 后台“影片与360°” |
| 留言、统计、Excel、二维码海报 | 后台相应菜单 |
| 新增第四系列、第六门课程、第四部影片、更多展位、自由增减课程图片数量 | 需要开发人员修改数据结构和界面，再构建验证 |
| 页面布局、配色、按钮、学校 logo/主屏幕图标、固定标题、问卷题目和全站固定提示文字 | 需要修改现有源码；当前后台不是任意拖拽排版工具 |
| 域名、HTTPS、服务器、内网访问、数据迁移和自动备份 | 部署配置或运维工作，按实际环境执行 |

现有学校 logo、默认凤冠首页、“凤冠360展示”标题、文物图列 16:10、课程图片前置及已经确认的课程名称继续保留。需要更改这类已确认设计时，清楚描述目标，再在现有代码上调整。

后台运行资料在数据目录，GitHub 保存程序、默认素材和说明。以后换电脑维护，先查看 [HANDOFF.md](HANDOFF.md)、[PROJECT_CONTEXT.md](PROJECT_CONTEXT.md)、[MODULES.md](MODULES.md)；代码提交、后台内容保存、Sites 发布和完整数据备份是不同的保存动作。

正式分享二维码前仍需在用户所在地、关闭代理的苹果/安卓和微信中验证真实访问。Windows 双击、学校局域网及公网可达性以对应设备实测为准，不能用云端测试代替。


## 便携版一键备份

暂停后台上传后，双击根目录 `Windows_备份数据.bat`。备份当前 `data/portable/`，副本保存在 `backups/`；请复制到另一台设备保存。该脚本不会自动备份旧启动方式的data目录或Sites数据库。恢复数据仍需先停止服务、核对目录并保留旧副本，不提供未经核对的自动覆盖恢复。

软件局域网内容与现有Sites托管站分别保存；在电脑软件里编辑，不会自动同步到原Sites网址。将来若使用国内公网服务器，则以那台服务器的同一后台作为统一维护入口，观众扫码看到的就是该后台发布的内容。
