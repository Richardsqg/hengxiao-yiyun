横小艺韵 1.4.2-desktop
360与视频修复操作手册

更新：2026-10-21 · 适用原1.4.2-desktop / 1.4.2-desktop 2独立部署包

本手册中“原项目文件夹”指打开后能看到 package.json、runtime、dist 的那个目录。外层若还有一层 hengxiao-yiyun 文件夹，请继续打开到含这些文件的位置。不要选择ZIP文件本身，不要选择 dist 子目录。

推荐顺序：关闭旧服务 → 安装360添加包并导入91帧 → 安装对应系统的视频修复包 → 重启并验证。已经完成的步骤可以跳过。新Windows360包可保留已安装的视频修复，无需为了新增360再装一遍视频修复包。

一、先关闭正在运行的旧展馆服务

Windows

  1. 找到启动展馆时打开的黑色“命令提示符”或Windows终端窗口，里面通常显示展馆网址或“服务已启动”。
  2. 点一下窗口，在里面按 Ctrl+C，等服务结束。
  3. 如果出现“终止批处理操作吗(Y/N)”，输入 Y 后按回车，再关闭窗口。
  4. 只关闭浏览器页面不会停止后台服务。若由桌面程序或托盘图标启动，请使用该程序的“退出”操作。

确认方法：在浏览器重新打开并刷新 http://127.0.0.1:3000/api/health。若提示无法连接，说明默认3000端口的服务已停止；若仍显示 {"ok":true}，说明仍有服务运行。自定义端口以原启动窗口显示的端口为准。

找不到启动窗口时，先按 Ctrl+Shift+Esc 打开任务管理器，检查属于展馆的程序。如果不能确认，可在命令提示符运行下面的只读命令查看3000端口的进程编号，再在任务管理器“详细信息”按该PID核对命令行，只结束确认属于展馆的进程：

netstat -ano | findstr LISTENING | findstr ":3000 "

Mac

  1. 找到启动展馆的“终端”窗口。
  2. 点终端，按键盘上的 Control+C（不是Command+C）。
  3. 等出现命令提示符后再关闭该窗口。若没有服务窗口，先退出原桌面启动程序。

二、Windows添加第一组91帧360

准备两个已有下载：本次 Windows_凤冠360添加包_适配1.4.2-desktop_20261021.zip，以及你手上的 凤冠360_网页轻量包_91帧.zip。不需要重新下载整站。

  1. 按上一节关闭旧展馆。
  2. 分别右键两个ZIP，选择“全部解压”。凤冠素材解压后应有 frames 文件夹，里面是 frame_001.webp 至 frame_091.webp。
  3. 打开本次小添加包解压后的目录，双击 安装到原Windows包.bat。
  4. 窗口要求项目目录时，把原 1.4.2-desktop 中含 package.json、runtime、dist 的文件夹，从资源管理器拖入黑色窗口，再按回车。Windows可能自动加引号，保持原样即可。
  5. 窗口要求图片目录时，把素材解压后的 frames文件夹 拖进去，按回车。也可以拖包含frames的上一层目录。此处选择文件夹，不选择ZIP。
  6. 等待看到“第一组91帧凤冠已全部导入并校验”。安装器会自动将图片命名并放到 dist/assets/crown-01-frame-001.webp 至 crown-01-frame-091.webp，并接入第一展位。无需手动逐张改名。
  7. 打开原项目里的 Windows_启动.bat，或你此前能正常启动的原入口。服务窗口保持开启。
  8. 打开 http://127.0.0.1:3000，按 Ctrl+F5 刷新。进入第一展位，角度计数应显示“1 / 91”，拖动图片、点击左右箭头或播放按钮验证旋转。

中途取消图片目录选择时，不需要重新安装。以后双击原项目新增的 Windows_导入凤冠91帧_本次补充.bat，再拖入frames文件夹即可继续。

安装后，本手册也位于原项目 docs/DESKTOP_ADDONS_GUIDE_20261021.html，可离线打开。

三、Mac添加第一组91帧360

  1. 按第一节用 Control+C 停止旧服务。
  2. 解压之前提供的 Mac_小补充包_复用已有凤冠ZIP.zip。
  3. 双击 安装到原Mac包.command，在弹出的选择框中选原项目目录，即打开后有package.json、runtime、dist的那个目录。
  4. 继续选择你手上的 凤冠360_网页轻量包_91帧.zip。Mac这个入口直接读取原ZIP，不需要先拆开91张图片。
  5. 等待成功提示。日后在原项目里双击 macOS_本机启动_本次补充.command，打开 http://127.0.0.1:3000。网页按 Command+Shift+R 刷新。
  6. 若要手机扫码，改用 macOS_同WiFi扫码启动_本次补充.command。Mac会打开二维码页面；手机与Mac连接同一个路由器/Wi-Fi，用相机或微信扫描。保持终端窗口开启，Mac不要睡眠。

macOS弹出接收传入网络连接的提示时，允许Node。局域网使用Mac内网地址和本地素材，下载完成后的本地浏览不需要翻墙。切换Wi-Fi后重启入口并重新扫码；访客Wi-Fi或开启设备隔离的网络可能无法互访。

Mac若阻止打开.command，可右键该文件→打开；若明确提示“权限不够”，在原项目目录的终端执行 chmod +x macOS_*本次补充.command 后重试。

四、Windows安装视频上传/播放修复包

  1. 关闭正在运行的旧服务。
  2. 右键 Windows_视频上传播放修复补充包_20261020.zip，选择“全部解压”。
  3. 双击其中的 安装视频上传补充.bat。
  4. 把原项目中含package.json、runtime、dist的文件夹拖入窗口，按回车。等待看到“上传与播放器补充已安装”。
  5. 仍使用原 Windows_启动.bat 启动，打开 http://127.0.0.1:3000/admin；也可使用原“Windows_管理员后台.bat”。沿用原管理员密码。
  6. 在后台按 Ctrl+F5 刷新。点击“影片与360°”，在 FILM 01 的上传卡片选择要替换的MP4。
  7. 等编码检查完成，先点击下方本地预览的播放按钮。确认有画面且声音符合原片后，勾选“我已播放预览并确认画面正常，声音正常（原片无声除外）”。
  8. 点击“确认画面正常，上传并替换”，等待100%及发布成功提示。保持网页和服务窗口开启。
  9. 进入公开展馆的“影像展厅”，选择影片1，再播放、拖动进度验证。

五、Mac安装视频上传/播放修复包

  1. 在原终端按 Control+C 停止服务。
  2. 解压 Mac_视频上传播放修复补充包_20261020.zip。
  3. 双击 安装视频上传补充.command，选择原项目中含package.json、runtime、dist的目录。等待安装成功。
  4. 用原启动入口重新运行。已安装360补充时，可继续用本次补充的Mac本机或同WiFi入口。
  5. 在Mac浏览器打开 http://127.0.0.1:3000/admin；若当前以同WiFi入口启动，则使用启动窗口/二维码页面所显示的网址加 /admin。
  6. 按 Command+Shift+R 刷新后台，点击“影片与360°”，在FILM 01选择MP4。播放本地预览、确认画面和声音，勾选确认框，再点击上传替换。
  7. 等100%及发布提示，再到公开“影像展厅”检查影片1。

六、151MB有声音没画面时怎么处理

当前上传上限是 400 MiB，151MB在范围内，无需为了容量压到30MB。MP4后缀并不能保证里面的视频编码兼容Windows、Mac和手机。

本次修复会在上传前给出明确检查结果；失败时原影片继续保留。修复包不会自动改变已经上传文件的编码，也不会把原视频猜测成已修复。若被提示HEVC/H.265、高色深、缺视频轨或文件损坏，请从原片另存兼容版本：

项目导出选项
文件容器MP4
视频编码H.264 Baseline / Main / High
像素格式8位、4:2:0（yuv420p）
音频AAC-LC；原片静音可不带音轨
建议画幅720p或1080p

本机已有FFmpeg时：Mac在原项目双击 macOS_另存兼容视频.command 选择原片；Windows双击 Windows_另存兼容视频.bat，将原视频拖入窗口并回车。会在原片旁另存 原文件名-兼容版.mp4，原片不覆盖。回后台选择这个兼容版，按前面的预览和上传步骤操作。

本机没有FFmpeg时：入口会明确停止，不会自动下载大转码器。可用自己的视频工具按上表导出，再上传。仅把MOV、HEVC文件改成.mp4后缀不会改变编码。

七、常见情况与数据保留

  • 提示端口3000被占用：先停止旧服务，再打开一个启动入口；不要同时开旧、新两个启动窗口。
  • 360装好了却仍显示原序列：先强制刷新并确认第一展位。若后台第一展位以前已上传另一组序列，它会优先保留；登录后台→“影片与360°”→“360°环绕照片”→选择展位1→选择这次91张WebP→上传并启用。无需删除数据库。
  • 提示原包结构不匹配：先检查选的是不是含package.json、runtime、dist的项目目录。目录正确仍失败时，保留报错，不要手动替换整个runtime或dist。
  • 路径有中文或空格：直接从文件管理器把整个目录拖进命令窗口即可，脚本支持带引号的路径。
  • 密码、留言和其他上传素材：安装器不改写data内这些内容。程序运行后，正常提交留言等操作仍由原程序保存。
  • 程序备份：360接口备份在 backups/media-supplement-20261020；视频程序备份在 backups/video-upload-fix-20261020。需要撤回时先停止服务，按原相对目录恢复程序文件；不要删除data。

本次已验证云端独立版接口、91帧文件校验、补充安装与视频浏览器流程。用户1.4.2原ZIP及Mac/Windows真机不在云环境，原接口不匹配时会停止。原151MB视频未被读取，不能确认其具体编码。
