# Intel Mac：完整展馆软件与运行环境

本说明适用 **1.4.2 桌面包**，在原项目上补充 Intel Mac 启动工具。展馆页面、学校 logo、五门课程、三部视频、管理后台、360实拍序列、留言、Excel 和内容发布继续使用同一套程序。最新第一片仍为113秒、60fps、双声道的掐丝珐琅视频；没有另建展馆。

## 下载与首次打开

先在浏览器登录有仓库权限的 GitHub 账号（Richardsqg），再下载：

<https://github.com/Richardsqg/hengxiao-yiyun/archive/refs/tags/v1.4.2-desktop.zip>

仓库为私有，未登录可能显示404。同Wi-Fi扫码的观众不需要 GitHub 或 ChatGPT 账号。

1. 将整个 ZIP 解压到一个**新的、本机可写的文件夹**；不要覆盖原安装的 `data/`。不要只打开 `dist/index.html`，也不要直接在压缩包内启动。
2. 双击根目录 **`macOS_一键运行.command`**。首次会校验并从包内解压官方 Intel Node.js 24.22.0，之后启动会复用；不需要联网安装依赖。
3. 按提示选择：`1` 只在这台 Mac 查看；`2` 让同一个 Wi-Fi / 局域网的手机扫码查看。第一次由你在终端设置管理员密码，至少12个字符，输入时不显示。密码不要发到聊天、写进文档或提交 GitHub。
4. 服务就绪后自动打开私有“打开与扫码”面板，包含二维码、展馆入口和管理员登录按钮；面板也保存在 `data/portable/打开与扫码.html`。后台地址为启动窗口给出的展馆地址加 `/admin`。
5. 保持 Mac 开机、不休眠，并保留运行窗口。结束时在窗口按 **Control+C** 停止服务。

同一安装只保留一个启动窗口；已经运行时直接使用面板或浏览器地址，不要反复双击创建多个服务。

若 `.command` 双击提示“没有执行权限”，打开“终端”，输入 `bash` 和一个空格，将 **`macOS_一键运行.command` 文件拖进终端**，再按回车。备份文件也可用同样的方法运行。这种方法无需你手动输入中文或带空格的完整路径。

若系统对下载的脚本或运行程序显示安全拦截，先核对下载自自己的上述仓库，再按 macOS 的“右键 → 打开”或“系统设置 → 隐私与安全性”针对该文件的提示处理；不需要关闭系统整体安全保护。

## 环境、软件和插件要求

| 项目 | 正常运行完整软件时的要求 |
| --- | --- |
| 芯片 | **Intel 64位 Mac**，运行包为 `darwin-x64`；本次未附 Apple 芯片的运行包 |
| 系统 | **macOS 13.5 或更新**。左上角苹果菜单 → 关于本机可查看；官方 Node 24 的最低要求见下方来源 |
| 浏览器 | 使用系统可支持的较新 Safari、Chrome 或 Edge；浏览器负责展示页面，终端窗口负责运行后台 |
| Node.js / npm | 包内已附 Intel Node.js 24.22.0；正常运行和后台编辑无需另装 Node、无需运行 `npm install` |
| React / SQLite | 前端已经构建，SQLite 由 Node 内置；不需另装数据库服务器 |
| 浏览器插件、VS Code 插件 | **不需要**；上传图片、360照片组、兼容MP4、字幕、保存内容和Excel导出均为原生功能 |
| Homebrew / Xcode / Docker / Python | 正常使用不需要；没有为你在 Mac 上自动安装这些工具 |
| FFmpeg 与 ffprobe | **可选**：只有另行使用视频压缩/转码工具时需要；视频播放和上传现成兼容视频不需要 |
| Excel | 导出 `.xlsx` 不需安装 Excel；阅读导出文件可用 Excel、Numbers 或兼容表格软件 |

官方要求：<https://github.com/nodejs/node/blob/v24.22.0/BUILDING.md#supported-platforms>。内置包来源与 SHA-256 在 `runtime/macos/NODE-RELEASE.json`，官方校验清单在同目录 `SHASUMS256.txt`，许可证在 `LICENSE.txt`。启动解压后的位置为 `runtime/macos/.extracted/x64/`，不会提交到 Git。

若 Mac 系统低于13.5且无法升级，本次内置运行环境不适用，不会自动改成不符合项目要求的旧 Node。仍可将完整软件运行在符合要求的 Windows/Mac 电脑上，由这台旧 Mac 的浏览器在同一网络中访问；旧浏览器的实际兼容性需另测。

如果将来要修改 React/TypeScript 源码并重新构建，才需要安装包含 npm 的 Node.js **24.15及以上的24.x、低于25**，然后在项目目录执行 `npm ci`、`npm run build`、`npm test`。这是开发工作，后台常规编辑不需要这些命令。

## 手机扫码和后续内容编辑

选择2后，Mac 和手机必须连接同一局域网。若 macOS 提示“本地网络”权限，允许对应终端或 Node.js；如果防火墙拦截，允许该运行程序接收入站连接，无需关闭整个防火墙。学校访客网络隔离可能仍会阻止访问，需要学校网络人员协助。

手机扫码进入四个公开展区，管理员登录后可修改图文、替换图片和三个视频、上传真实360照片组、查看留言与统计、导出Excel。每个菜单和当前编辑范围见 [软件使用指南](SOFTWARE_GUIDE.md)。仍缺的六个凤冠展位和全部真实整圈素材见 [素材清单](MEDIA_INVENTORY.md)，不要把现有照片当成已完成的八件360作品。

扫码图片和私有面板每次启动会按实际网络地址生成。可从面板进入登录保护的展板打印二维码。更换网络或IP后应重新启动并更新分享的二维码；电脑休眠或服务关闭后不能访问。

同Wi-Fi模式不调用境外网站，适合现场展示；校外、不同网络或手机流量访问仍需独立公网服务器及HTTPS网址。没有因增加 Mac 启动工具就完成国内公网部署，也没有购买服务器或域名。方案见 [访问方式](ACCESS_OPTIONS.md)。

## 数据保存、备份与换电脑

Mac 和 Windows 一键运行都使用各自安装目录下的 **`data/portable/`**，与旧 `data/`、`data/local-preview/` 分开。初始包没有你的密码、留言数据库或后台上传内容；首次运行才在本机创建。

备份前暂停后台上传，再双击 **`macOS_备份数据.command`**。完整备份保存到 `backups/`，含配置、数据库和上传媒体；请另存到其他设备并私密保管。Excel不能替代完整备份。

如将已有内容从 Windows 迁到 Mac，先备份，再停止旧服务与新服务，保留双方现场副本后核对要迁移的 `data/portable/`。不要让两台电脑在云盘或网络共享中同时读写一个SQLite目录。当前没有自动同步或一键覆盖恢复功能；如已有真实数据，请先核对路径再安排迁移。GitHub下载程序也不会自动下载 Sites 原站的线上数据库。
