# 凤冠360与掐丝珐琅视频 · Mac增量补充

本补充针对原横小艺韵独立部署包，不需要重新下载整站，不需要 npm install 或重新构建网页。

## 安装到原 1.4.2-desktop 2 包

1. 先关闭旧展馆的启动窗口。
2. 解压小补充包，双击其中的「安装到原Mac包.command」。选择原部署包解压后包含 package.json、runtime、dist 的项目目录。
3. 小补充包会再让你选择手上已有的「凤冠360_网页轻量包_91帧.zip」。保留ZIP格式选择即可，不必手动拆成91张再上传，也不需要重新下载图片。导入会逐帧校验。
4. 以后从原项目目录双击新增的「macOS_本机启动_本次补充.command」或「macOS_同WiFi扫码启动_本次补充.command」。不要同时开启旧启动窗口。

若下载的是含图片的补充包，安装时不用再选凤冠ZIP。若中途取消导入，可从原目录双击「macOS_导入凤冠91帧_本次补充.command」继续。

安装器逐个加入新增文件，不要自行用Finder的“替换文件夹”覆盖整个 scripts、runtime、src 或 dist。原包结构不匹配时会停止，不会猜测覆盖。当前云环境没有用户的 1.4.2-desktop 2 原ZIP，已验证的是本仓库独立版结构及兼容性检查，未做该原包或Mac/手机真机实测。

## 大视频单独放置

本次「掐丝珐琅.zip」超过当前环境32 MiB附件读取上限，无法取出、检查或转码其中的视频。因此补充包不包含该大视频；请使用你手上的原ZIP。

先解压该ZIP，找到实际MP4，执行以下任一操作：

- 双击原项目目录新增的「macOS_导入第一部视频_本次补充.command」，选中解压后的MP4。它会复制并正确命名，目标已有视频时会停止。
- 或把MP4移动到原项目的 `dist/assets/` 内，文件名设为 `film-01-qiasi.mp4`。移动可避免额外保留一份已解压的大视频。

最终位置：`原项目目录/dist/assets/film-01-qiasi.mp4`。不要把ZIP本身放到这个位置。MOV不能仅改后缀；如果实际文件是MOV，请先导出为H.264视频/AAC音频的MP4。导入器只核对容器标记，不代表已验证真实视频的编码或内容。

放好后关闭旧启动窗口，再用本次入口启动。「影像展厅」第一项会使用新视频；课程内容、第二与第三部视频保持原样。未放入新视频时，仍显示原第一部图文导览，避免出现坏链接。后台已上传的自定义视频仍优先，若第一项已被后台替换，请从后台重新上传这部视频或继续使用原自定义内容。

## Mac本机与同Wi-Fi手机

- 本机入口打开 `http://127.0.0.1:3000`。
- 同Wi-Fi入口监听Mac局域网地址并自动打开大二维码页面。手机和Mac连接同一个路由器或Wi-Fi，用手机相机或微信扫描；Mac也可点击二维码下的网址。
- 使用内网IP和本地媒体，不依赖海外站点或在线二维码服务，局域网访问不需要翻墙，也不要求连接互联网。Mac必须开机且启动窗口保持开启。
- macOS弹出网络权限时允许Node接收传入连接。若扫码打不开，检查手机与Mac是否同网、是否为访客Wi-Fi或启用了设备隔离。切换Wi-Fi后重新启动并扫描新二维码。
- 首次打开.command若被macOS阻止，可右键→打开。若提示权限不够，在该目录终端执行 `chmod +x macOS_*本次补充.command` 后再打开。需要原包的Node.js 24.15或更新的24.x运行环境；本补充不附带另一份Node。

## 添加了什么

- 第一组原始91帧透明WebP，路径为 `dist/assets/crown-01-frame-001.webp` 至 `crown-01-frame-091.webp`，不重压、不打乱、不复制其他展位。
- `src/media-supplement.json`：素材顺序、大小和SHA-256清单，以及第一部视频路径。
- `runtime/media-supplement.mjs` 与新增脚本/启动入口：在原展馆接口外接默认素材、导入原ZIP和MP4、生成局域网二维码。
- 对 `runtime/storage.mjs` 只增加补充接口包装；安装前原文件保存在 `backups/media-supplement-20261020/storage.mjs`。不替换原server、前端构建、package.json或Mac旧入口。

密码、已存配置、留言和其他展位不在补充包中，也不由安装器改写。网页正常运行时仍按原逻辑保存留言等操作。已有后台上传的第一组旋转序列优先于新默认序列；要替换该自定义序列，请在后台上传这次91帧，不需要删除数据库。

如要撤回补充：先关闭服务，把上述备份的storage.mjs复制回runtime/storage.mjs，然后使用原启动入口。无需删除data目录或重设密码。
