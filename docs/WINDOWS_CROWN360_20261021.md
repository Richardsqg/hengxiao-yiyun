# Windows第一组凤冠360增量包

用于原1.4.2-desktop中含package.json、runtime、dist的项目目录。

先在旧服务的命令窗口按Ctrl+C，出现终止批处理提示时输入Y再回车。仅关闭浏览器不会停止服务。

1. 解压本次Windows小添加包，并解压手头原来的凤冠360_网页轻量包_91帧.zip。
2. 双击安装到原Windows包.bat，把原项目文件夹拖入窗口后回车。
3. 把素材解压后的frames文件夹（含frame_001.webp至frame_091.webp）拖入窗口后回车。也支持包含frames的上一层目录。
4. 成功后使用原Windows启动入口运行；网页Ctrl+F5刷新，第一展位应有91帧计数。

不需要重新下载整站或安装额外解压工具。只添加图片和默认序列接口，不改写data里的密码、留言，不覆盖已安装的视频修复。已有后台上传序列仍优先。

完整Mac/Windows操作见同目录 DESKTOP_ADDONS_GUIDE_20261021.html，可离线打开。
