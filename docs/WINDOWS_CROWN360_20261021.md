# Windows第一组凤冠360增量包 v2

本版改用文件夹选择框，避免旧入口拖入文件夹时窗口关闭的问题。黑色窗口会在结束后停留；日志位置会显示在窗口里。尚未收到用户电脑的实际错误日志，不能确定旧入口关闭的具体原因。

1. 先在旧服务窗口按Ctrl+C停止展馆，提示终止批处理时输入Y并回车。
2. 全部解压本次v2添加包和原凤冠91帧ZIP。
3. 普通双击安装到原Windows包.bat。在第一个选择框里选原项目文件夹，里面应有package.json、runtime、dist，然后点确定。不用拖入黑色窗口。
4. 在第二个选择框里选原素材解压后的frames文件夹（含frame_001.webp至frame_091.webp），点确定。也支持包含frames的上一层目录。
5. 成功后用原Windows入口启动，网页Ctrl+F5刷新，检查第一展位91帧。

不需要管理员权限或重新下载整站；不改写data，不覆盖已经安装的视频修复。已有后台上传序列仍优先。若有报错，请保留窗口里的完整文字和日志。

完整Mac/Windows说明见同目录DESKTOP_ADDONS_GUIDE_20261021.html，可离线打开。
