03　先在自己的电脑打开

  1. 将压缩包完整解压。不要直接在压缩包内双击程序。
  2. 打开 Node.js 官方下载页，选择 24.x LTS（至少24.15）。Windows 选 .msi，Mac 选 .pkg，按默认选项安装。
  3. Windows 双击 Windows_启动.bat。Mac 可在“终端”输入 cd （后面有空格），把解压后的 fenghua-mainland 文件夹拖进去，按回车，然后运行下方命令。
node scripts/configure.mjs
node runtime/server.mjs
  1. 第一次配置，网址填 http://localhost:3000。设置至少12个字符的管理员密码，再输入一次；输入密码时屏幕不显示字符。没有备案号就按回车留空。
  2. 看到“服务已启动”后，在浏览器输入 http://localhost:3000。后台是 http://localhost:3000/admin。
  3. 试着填写一条问卷，去后台看统计并导出 Excel。测试留言保存在电脑的 data 文件夹。关闭命令窗口会停止本机服务。
本机地址只能用于这台电脑的试用，不能把它生成的二维码发给其他人扫码。公网使用必须完成下面的服务器部署。网页无需通过双击 dist/index.html 打开，也不用安装微信开发者工具。

04　部署到正式服务器

下面以全新的 Ubuntu 24.04、x86_64 Linux 云服务器为例。如果是已有学校服务器，请由管理员合并配置，避免覆盖学校其他网站。

A. 在云控制台准备资源

  1. 登录腾讯云或阿里云，完成账号实名认证。您本人操作身份核验与付款；不要把密码、身份证照片或云 API 密钥发到聊天中。
  2. 购买并实名认证域名，选一台有公网 IP 的服务器。内地服务器先按服务商流程办理备案，通过后再对外提供服务。服务器配置建议见上表。
  3. 在域名的“DNS解析”中添加一个 A记录：主机记录例如 gallery，记录值填服务器公网 IPv4 地址。最终网址就类似 https://gallery.您的域名。
  4. 在服务器防火墙或安全组开放 TCP 80、443；SSH 的22端口仅对管理员使用。不要把3000端口开放给全网。若没有配置 IPv6，不要添加无效的 AAAA 记录。

B. 连接并上传文件

在云控制台点击服务器的“登录”或“远程连接”。也可使用 WinSCP（Windows），以 SFTP 方式上传：主机填公网 IP、端口22、用户名按云控制台显示，使用您自己的密钥或密码。Mac 可使用系统终端的 scp。先把本次压缩包上传到服务器的 /tmp/fenghua-mainland.zip。

在服务器终端依次运行。以下命令只适用于尚未安装本项目的新服务器；更新现有项目先看第07节。

sudo apt-get update
sudo apt-get install -y unzip curl xz-utils ca-certificates
sudo mkdir -p /opt/fenghua-unpack
sudo unzip /tmp/fenghua-mainland.zip -d /opt/fenghua-unpack
sudo mv /opt/fenghua-unpack/fenghua-mainland /opt/fenghua

C. 安装 Node.js 24

本包不需要在服务器执行 npm install。若服务器已有24.15以上的24.x版本，可跳过安装。2026-10-12 查阅官方下载页显示24.21.0为24.x LTS版本；安装其他更新的24.x补丁版也可以。

cd /tmp
curl -fSLO https://nodejs.org/dist/v24.21.0/node-v24.21.0-linux-x64.tar.xz
curl -fSLO https://nodejs.org/dist/v24.21.0/SHASUMS256.txt
sha256sum --ignore-missing --check SHASUMS256.txt

必须看到上述压缩文件校验为 OK 再继续：

tar -xJf node-v24.21.0-linux-x64.tar.xz
sudo install -m 755 node-v24.21.0-linux-x64/bin/node /usr/local/bin/node
node --version

如果服务器下载不成功，可从电脑上的 Node.js 官网下载同一 Linux x64 压缩包及校验文件，再通过 SFTP 上传到 /tmp。ARM 服务器不能使用这里的 x64 安装包，应由管理员改用对应的 arm64 版本。

D. 设置正式网址与后台密码

cd /opt/fenghua
sudo /usr/local/bin/node scripts/configure.mjs
sudo bash deploy/install-service.sh

网址填写您刚设置的 https正式域名，不是服务器内网地址。设置新的后台密码。填写真实备案号；尚未取得的项目留空，不能随意填写。脚本会生成二维码和 Caddy 域名配置。运行常驻服务后，关闭远程连接不会关闭展馆。

E. 安装 Caddy 并开启 HTTPS

Caddy 用来接收80/443端口请求、为域名申请证书，再转发到本机3000端口。按 Caddy 官方安装页中 Debian / Ubuntu 的 Stable releases步骤安装。安装时用服务器终端执行该页命令，不在自己电脑上执行。若软件源访问失败，请让服务器管理员使用可验证的安装包处理。

Caddy 安装完成后，在这台全新服务器上运行：

cd /opt/fenghua
sudo cp /etc/caddy/Caddyfile /etc/caddy/Caddyfile.before-fenghua
sudo cp deploy/Caddyfile /etc/caddy/Caddyfile
sudo caddy validate --config /etc/caddy/Caddyfile
sudo systemctl reload caddy
sudo systemctl status fenghua --no-pager

现在用浏览器打开正式域名。若 HTTPS 证书未就绪，先核对域名解析、80/443端口和 Caddy 日志，不要使用忽略证书错误的办法验收。诊断命令：

sudo journalctl -u fenghua -n 50 --no-pager
sudo journalctl -u caddy -n 50 --no-pager

正式上线前按云服务商要求完成网站信息与备案展示；公安联网备案等后续事项按当地要求办理。配置脚本预留了备案号和官方查询链接的展示位置。

05　GitHub 在这里怎么用？

您的 GitHub 账号已连接，但本次未返回可访问的仓库，也没有创建或写入任何仓库。可以新建一个私有仓库，例如 fenghua-gallery，再把仓库链接提供给我；如插件访问范围有限，需要在 GitHub 的应用权限中把这个仓库授予连接。

本包附有 .gitignore：data、备份目录、环境文件和部署域名配置不会作为源码提交。不要把观众留言、后台配置或服务器密钥传进公开仓库。

手动管理代码可安装 GitHub Desktop，登录后添加此解压文件夹，并发布为 private repository。网页源文件在 web，服务器在 runtime，可以重建的共享源文件在 src。仅当修改前端源码后，才需要在开发电脑上安装依赖和构建：

npm install
npm run build
npm test

把代码传到 GitHub 不等于网站已经上线。正常观看不需要观众打开 GitHub，网站运行也不会每次向 GitHub 下载素材。暂不接入自动部署，以免源码更新意外覆盖正式服务；准备好仓库和服务器后可以再配置。

06　获得真正能扫码的二维码

  1. 先确认正式域名能在手机移动网络下打开。
  2. 访问网站，点击右上角“扫码观展”→“保存二维码”。下载的是 PNG，适合微信保存和打印。
  3. 也可从服务器 data/gallery-qr.png 下载；data/gallery-qr.svg 是可无损放大的矢量版。
  4. 用另外一部手机微信扫码，确认进入展馆。二维码的四周白边必须保留，不要裁切，也不要叠加图案。
  5. 至少用一部苹果手机、一部安卓手机、微信和电脑检查：四个导航、缩放、首部视频播放与拖动、问卷提交、后台收到、Excel打开。
先实测再印刷。域名不变、只换服务器时，DNS正确迁移后二维码可以继续用。如果改域名，旧二维码本身不会自动改变：保留旧域名并设置跳转，或更换印刷二维码。不要把本机测试或旧 ChatGPT 展示站的二维码误当成新站二维码。

07　管理员日常操作与备份

查看留言和补充视频

后台地址是 正式域名/admin。密码登录后可以筛选留言、标记已阅、导出 Excel。Excel 包含留言详情和问卷统计两张工作表；每次最多20,000条。视频在“影片与360°”上传，MP4每部不超过400 MB，建议 H.264 + AAC。上传成功后，观众刷新页面即可看见。

定期备份

先暂停后台上传，再在服务器运行：

cd /opt/fenghua
sudo /usr/local/bin/node scripts/backup.mjs

把输出显示的 backups/fenghua-时间 文件夹下载到另一台电脑保管。备份包含数据库、视频图片和密码哈希；不要公开分享。更新网站时保留整个 data 文件夹。服务器到期、删除磁盘或丢失data目录，都可能丢失留言和上传文件。

忘记密码／更换正式网址

cd /opt/fenghua
sudo systemctl stop fenghua
sudo /usr/local/bin/node scripts/configure.mjs
sudo chown -R fenghua:fenghua data
sudo systemctl start fenghua

重新配置会设置新密码并清除旧登录会话，不会主动删除留言。改了域名还要更新 DNS 与 Caddy 配置，重新生成的二维码要重新验收。只改密码不必修改 Caddy。

恢复备份

由服务器管理员操作：停止fenghua服务；先把当前data文件夹改名留存；创建一个新的data目录；把所选备份里的 gallery.sqlite、config.json 和 media 放进去；设置目录所有者为fenghua、目录权限700、配置文件600，再启动服务。不要在正在运行的数据库上覆盖文件，也不要把旧的sqlite-wal或sqlite-shm文件混入恢复目录。备份恢复后使用备份时的后台密码。

更新程序

先备份，停止服务，把新版本的 dist、runtime、src、web 与脚本换入；不要覆盖 data、backups 或正式域名配置。启动后检查页面和留言数。当前版本面向单台服务器，不要把同一数据库同时挂到多个运行实例。
